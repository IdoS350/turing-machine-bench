Program

    Syntax

    One rule per line: state read write move next

    • _ is the blank symbol. Symbols are single characters; spaces in the input become blanks.
    • move is L, R, or S (stay).
    • * as read matches any symbol without a more specific rule; as write leaves the cell unchanged; as next keeps the current state.
    • Comments start with ;. Arrows and commas are ignored, so q0, 1 -> 0, R, q1 works too.
    • The machine halts on entering an accept/reject state, or when no rule applies (an implicit reject when accept states are defined).
